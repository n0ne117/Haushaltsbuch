Buchungsregeln

💳 Kreditkarte

Jeden Kartenkauf als Ausgabe auf dem Konto buchen, von dem die Kreditkarte später abgebucht wird (z. B. Girokonto), optional mit Tag #Kreditkarte. Die monatliche Kreditkartenabrechnung am Kontoauszug wird nie gebucht – sonst wäre alles doppelt.

💶 Bargeld

Bankomat-Abhebung = Umbuchung Girokonto → Bargeld. Barzahlungen = Ausgabe vom Konto „Bargeld“.

📈 Aktien / Sparplan

Kauf = Umbuchung Girokonto → Depot. Verkauf = Umbuchung Depot → Girokonto. Dividenden = Einnahme (Kategorie „Kapitalerträge“) auf das Konto, das sie erhält. Depotgebühren = Ausgabe. Kurswerte werden nicht erfasst: der Depot-Saldo bedeutet „netto investiert“, nicht den aktuellen Wert.

🤝 Geld zwischen Partnern

Immer als Umbuchung zwischen den beiden Konten – nie als Einnahme oder Ausgabe.

📊 Wie gerechnet wird

  • Einnahmen = Summe aller Einnahmen.
  • Ausgaben = Summe aller Ausgaben.
  • Gespart = Umbuchungen auf Spar-/Depotkonten minus Umbuchungen von dort zurück auf andere Konten.
  • Saldo = Einnahmen − Ausgaben − Gespart.
  • Umbuchungen zwischen normalen Konten (z. B. Bankomat) zählen nirgends.
